# Analysis Summary — Student Performance Data Analysis

## 1. Project Overview

This project analyzes student academic performance using Python and
data analysis and visualization libraries.

The dataset contains 20 student records with information about gender,
age, attendance, study hours, and marks in Mathematics, Science, and
English.

## 2. Tools and Libraries Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 3. Data Analysis

The dataset was explored to understand its structure and quality.

The following tasks were performed:

- Checked the number of rows and columns.
- Identified column names and data types.
- Checked for missing values.
- Checked for duplicate records.
- Generated statistical summaries.
- Calculated subject-wise average marks.
- Filtered students based on attendance.
- Sorted students according to Mathematics marks.
- Performed gender-wise performance analysis.
- Calculated average marks for each student.

## 4. Visualizations

Six visualizations were created:

1. Distribution of Student Average Marks
2. Number of Students by Gender
3. Average Marks by Subject
4. Attendance vs Average Marks
5. Correlation Heatmap of Student Performance
6. Study Hours vs Average Marks

## 5. Key Findings

- English has the highest average marks among the three subjects.
- Science has the second-highest average performance.
- Attendance shows a relationship with overall academic performance.
- Study hours also show a relationship with average marks.
- The correlation heatmap provides an overview of relationships between
  different academic factors.
- Average marks can be used to identify students with stronger overall
  academic performance.

## 6. Conclusion

The project demonstrates how Python can be used to perform data
cleaning, analysis, statistical calculations, and visualization.

Pandas was used for data manipulation and analysis, NumPy for numerical
operations, and Matplotlib and Seaborn for creating visualizations.

The analysis provides useful insights into student academic performance
and helps identify relationships between attendance, study habits, and
academic marks.
