# 📊 Student Performance Data Analysis

## 📌 Project Overview

This project analyzes student academic performance using Python,
Pandas, NumPy, Matplotlib, and Seaborn.

The objective is to understand student performance and identify
relationships between attendance, study hours, and academic marks.

---

## 🎯 Objectives

- Analyze student academic performance
- Explore the dataset using Pandas
- Perform statistical analysis
- Calculate subject-wise average marks
- Analyze attendance and study hours
- Identify relationships between different variables
- Create meaningful data visualizations
- Identify important trends and patterns

---

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📂 Dataset

The dataset contains information about students, including:

- Student ID
- Gender
- Age
- Attendance
- Study Hours
- Mathematics Marks
- Science Marks
- English Marks

The dataset is stored in:

`student_performance.csv`

---

## 🔍 Data Analysis Performed

The following analysis was performed:

1. Dataset creation and loading
2. Data exploration
3. Data type checking
4. Missing value checking
5. Duplicate value checking
6. Statistical analysis
7. Student filtering
8. Student sorting
9. Gender-wise analysis
10. Subject-wise average marks
11. Student average marks calculation
12. Correlation analysis

---

## 📊 Visualizations

Six visualizations were created:

1. Distribution of Student Average Marks
2. Number of Students by Gender
3. Average Marks by Subject
4. Attendance vs Average Marks
5. Correlation Heatmap
6. Study Hours vs Average Marks

---

## 📈 Key Findings

- English has the highest average marks among the three subjects.
- Attendance shows a relationship with overall academic performance.
- Study hours show a relationship with average marks.
- The correlation heatmap helps identify relationships between
  attendance, study hours, and subject marks.
- Average marks help identify students with stronger academic
  performance.
